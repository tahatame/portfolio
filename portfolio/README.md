## 🛠️ دليل التشغيل على Visual Studio Code (VS Code)

### 1. المتطلبات الأساسية
* محرر الأكواد **VS Code**.
* إضافة **Live Server** على VS Code.

### 2. خطوات الفتح والتشغيل
1. قم بفتح برنامج **VS Code**.
2. اختر **File** -> **Open Folder** ثم اختر مجلد `portfolio`.
3. تأكد من ثبات هيكل المجلدات كالتالي:
   ```text
   portfolio/
   ├── index.html
   ├── css/style.css
   ├── js/script.js
   └── README.md
